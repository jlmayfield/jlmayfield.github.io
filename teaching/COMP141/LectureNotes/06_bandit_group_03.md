# You Found Your File, Now What?

Now that you can run sophisticated file searches, its time to learn how to use powerful shell tools to search and work within a file and unlock the shell superpower that is **redirects**. To make use of redirects we must broaden our view of a computing system to include a more technical perspective on **Input/Output**, or *I/O*. The payoff is the ability to engage the computer in increasingly complex work by combining and chaining commands.
